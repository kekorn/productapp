Docker parancsok:

Minta környezet létrehozása:
mkdir -p /var/www/html, vagy New-Item -ItemType Directory -Force -Path "./var/www/html"
 echo hello from docker >> /var/www/html/index.html, vagy 
"hello from docker" | Out-File -FilePath "./var/www/html/index.html" -Encoding utf8 -Append

Docker konténer létrehozása: docker run -d -p 8081:80 --name="myapache" -v /var/www/html:/var/www/html httpd

Futó konténerek listázása: docker ps

Összes konténer listázása: docker ps -a

Konténer leállítása: docker stop <(rész)konténerid>

Konténer indítása: docker start <(rész)id>

Konténer újraindítása: docker restart <(rész)id>

Konténer erőltetett bezárása: docker kill <(rész)id>


Konténer törlése: docker rm <konténer azonosító (elég az eleje addig, amíg már egyedi)>

docker run -it busybox 
(CTRL+P, CTRL+Q ) lecsatlakozás, de fut tovább
(exit) leállít

Docker saját  apache shell megnyitása: docker exec -it myapache sh

Docker inspect <ID> | less
Docker inspect --format='{{.NetworkSettings.IPAddress}}' containername
Docker inspect --format='{{.State.Pid}}' containername
:Konténerek ellenőrzése

Ps: Gazda operációs rendszer folyamatai

Docker image (ls): Dokker imagek listázása

docker image inspect <ID>: dokker image ellenőrzése

Docker image rm: Image törlés

Docker image rm -f: Image törlés a csatlakoztatott konténerekkel együtt (leállítottakkal is)

Docker logs <ID>: Hibanaplók olvasása

docker run -d --name mydb -e MYSQL_ROOT_PASSWORD=password mariadb
docker run: Új konténer indítása egy image-ből.
Detached mode = a konténer háttérben fut. Ha nem használnád, akkor a MariaDB logsorai betöltenék a terminálodat.
A konténer neve: mydb. Ez azért fontos, mert így könnyebb:
    - hivatkozni rá (docker stop mydb, docker logs mydb)
    - docker compose nélkül is kezelni
Környezeti változó beállítása a konténerben: -e (environment variable) MYSQL_ROOT_PASSWORD (a MariaDB root felhasználó jelszava) Ez az alapértelmezett módja a MariaDB/Mysql konténer konfigurációjának
mariadb: Az image neve, amelyből a konténer indul.
port beállítása (-p 3306:3306 \ az image neve előtt)
